# Fantasia Group — Design 1 — Paper & Thread (light editorial)

Home page concept for client approval. Next.js 16 (App Router), React 19, Tailwind CSS v4, Motion.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this folder as a project on Vercel (framework preset: Next.js). No environment variables are required.

## Content

All copy lives in `src/data/site.ts` and follows the "Fantasia Group Website Copy / Designer Handoff" document.
Values marked PLACEHOLDER (email, phone, address, year established) must be confirmed by the client before launch.

Images in `public/images` are AI-generated placeholders in the intended art direction; replace with client photography when available.
The logo in `public/brand` is the low-resolution PNG from fantasia.lk — request the vector (SVG/AI) master from the client.
